# gakko-calendar

学校の 1 日の区切り（朝・1〜6 限・昼休み・放課後）で、Google カレンダーの予定と自分の時間割を一覧にする表示ページ。
iPhone・iPad・Windows・Mac のブラウザで見る。

- 設計・決めたこと・未確定: desk の `knowledge/period-calendar.md`
- 試しのデータで見る: ページの URL の後ろに `?sample` を付ける

## 中身

| ファイル | 何か |
|---|---|
| `index.html` | 表示ページ（1 枚で完結。GitHub Pages で公開する） |
| `Plan.gs` | 授業計画のブック（学校アカウント。生徒のデータは入れない）に貼る GAS。シートを作り、時間割から授業の行を並べ、成績のブックの課題管理から課題の一覧だけを引く（下の「授業計画のブック」） |
| `Code.gs` | 時間割のスプレッドシートの「拡張機能 → Apps Script」に貼る GAS。合言葉が合ったときだけ、時程・時間割・予定を JSON で返す |

## しくみ

1. 個人アカウントの GAS が、「カレンダー」シートに書いたカレンダー（個人・学校の全職員・祝日）と、「時程」「時間割」「会議」シートを読む
2. 表示ページが、合言葉を付けて GAS の Web アプリを呼ぶ。前に取った分はそのブラウザに貯めておき、開いたらまずそれを出す
3. 1 週ずつ出す。左右にスワイプするか ◀ ▶ で週を動かす。スワイプの間は表が指に付いて動き、隣の週（取ってあればその週、まだなら授業だけ薄く）が横から見える。表は動かした向きに横へ滑って切り替わる（端末で視差効果を減らしていれば、すぐ切り替わる）。前後の週は裏で先に取っておく。まだ取っていない週は、授業だけ薄く出して「読み込み中…」にする
4. 予定は時刻が重なる校時のマスに出す。名前は最初のマスにだけ書き、続くマスは細い帯。授業と同じマスなら授業の下。どの段にも重ならない予定（休み時間に収まるもの）は、その前の校時の段に出す。朝より前の予定は「0時〜」の段（時程の朝に開始の時刻があるとき。無ければ朝の段）。終日の予定は「終日」の段。祝日は授業を出さない。授業は「クラス 授業名」を 1 行で出し、入らなければ字を 6px まで小さくする。マスを押すと中身が下に出る（「閉じる」は左）
5. 朝より前（0 時〜）と放課後のあとは、ふだん畳んである。左の見出し（`0時〜`・`放課後`）を押すと開いて 1 時間ごとの段になり、もう一度押すと畳む。畳んでいても、その時間の予定は畳んだ段に出る。開いたかどうかは、その機械のブラウザが覚えておく。勤務の終わりが分かる日は、放課後から勤務の終わりまでのマスに色を付け、「勤務〜17:15」は勤務の終わりの時刻を含む段に出す（畳んでいるときは放課後の段）
6. マスを押したときの下の欄に「＋ 予定を追加」が出る。押すと、そのマスの日時を入れた Google カレンダーの作成画面が開く（保存は作成画面でする。このページは書き込まない）。設定の「予定を追加するアカウント」にメールアドレスを入れると、アカウントごとのボタンになる
7. 設定は、見出しの右の ⚙ で開く

名前の決まり（表示がこの名前を見ている）:

- 「カレンダー」シートの表示名が `祝日` のものは、祝日として扱う（紫・その日の授業は出さない）。`学校` と `個人` は色が決まっている（それ以外は 3 色目）
- 「時程」シートの、長さが 20 分以下の段（朝・終礼など）と、`昼` で始まる段（`昼`・`昼休み`）は、低く出す
- 校時の名前が `朝` の段は、予定をマスの下（1 限の側）に寄せる
- 校時の名前が数字だけなら、マスを押したときに「限」を付けて出す
- 「時程」シートの D 列から右に「考査 開始」「考査 終了」のような見出しの列の組があり、表示名が `学校` の終日の予定にその言葉（`考査`）が入る日は、その日だけ授業を出さず、予定をはめる時刻と、マスを押したときの時刻をその列のものにする。段の並びと左の時刻はふだんのまま（週で揃えるため）。列が空の段は、ふだんの時刻のまま（ただし、考査の時刻で延びた段のすぐあとの段（昼など）は、重ならないように始まりを遅らせる）
- 表示名が `学校` の終日の予定を、括弧の外の読点・カンマで分け、括弧の中に `限` と数字があれば（`(5限)`・`(5,6限)`・`(5.6限)`・`(5・6限)`・`(4限目)`。全角も可）その校時の段に、`(放課後)` なら放課後の段に、括弧を除いた名前で出す。括弧が無く、「会議」シートの名前が入っていれば、その時刻で出す（括弧のほうを優先）。終日の段にも元のまま出す
- 表示名が `学校` のカレンダーの終日の予定が `6)`・`8)`・`10)` で始まれば（全角も可）、その日の勤務の終わり（15:15・17:15・19:15）として「勤務〜17:15」と出し（出す段は上の 5）、頭の番号は消して出す。番号だけの予定は終日の段に出さない。ほかの番号は扱わない（`index.html` の `WORK_END`）

**このリポジトリは公開。** 合言葉・GAS の URL・カレンダー ID は、コードにも git にも入れない（合言葉はスクリプトのプロパティ、ID はスプレッドシートの「カレンダー」シート、URL と合言葉は各機械のブラウザ）。

## スプレッドシートの形

| シート | 列 |
|---|---|
| 時程 | 校時 / 開始 / 終了（例: `1` / `8:50` / `9:40`）。表の段の順はこの順。右に「考査 開始」/「考査 終了」の列を足せる（上の名前の決まり） |
| 時間割 | 校時 / 月 / 火 / 水 / 木 / 金。マスは「クラス 授業名」を半角スペースで区切る（例: `3-3 美術1`） |
| カレンダー | ID / 表示名 / 出し方（`タイトル` か `予定あり`） |
| 会議（任意） | 名前 / 開始 / 終了（例: `職員会議` / `16:00` / `17:00`）。終了が空なら 1 時間。シートが無くても動く |

## 授業計画のブック（`Plan.gs`）

学校アカウントに置く、授業の計画と進捗のブック。個人アカウントにはこのブックだけを編集者で共有する（成績のブックは共有しない）。成績のブックとは `IMPORTRANGE` でつなぐ。カレンダーから読む形は、まだ作っていない。

| シート | 列 | 中身 |
|---|---|---|
| 設定 | 項目 / 値 / メモ | B2・B3 に期間の始まりと終わり（1 学期の始業〜3 学期の授業の終わりなど、1 年まるごと）。「時間割の切り替え」の見出しの下に、使い始める日と時間割のシートの名前を 1 行ずつ（日付の無い行は初めから）。「課題を引くブック」の見出しの下に、成績のブックの URL とシートの名前（空なら `課題管理`）を 1 行ずつ。どちらも空の行で終わり |
| 時間割（いくつでも） | 校時 / 月〜金 | マスは「クラス 授業名」（例: `31 美術1`）。`o31美術1` のように、頭に英字が付いて空白が無くても、数字をクラスとして読む。`選択3e`・`選択3美` は、全体をクラス（数字は学年）、最後の字から授業名（`e` → eスポーツ、`美` → 美術）にする。3 学期の 3 年が抜けた時間割などは、別のシート（例: `時間割_3学期`）にして、設定の「時間割の切り替え」に書く |
| 日 | 始まり / 終わり / 種類 / メモ | 考査・短縮・休み・行事の日だけ書く。続く日は 1 行で（例: 冬休み、考査の期間）。終わりが空なら 1 日。考査と休みの日は授業の行を作らない |
| 授業 | 日付 / 曜 / 校時 / クラス / 授業名 / 状態 / 実施ID / 単元 / 内容・進捗 / 回 | 1 コマ 1 行。「回」は式で、同じクラス・同じ単元の何回目か（中止を除く） |
| 単元 | 単元 / クラス / 予定の回数 / 割り当て済み / 済み / メモ | クラスは `31,32,33` のようにまとめて書いてよい。割り当て済みと済み（今日まで）は、授業のシートの単元の列にその単元が書かれた行を、クラスごとに `31: 3 / 32: 4` の形で式で数える |
| 課題 | 課題名 / 対象クラス / 提出期限 / 状態 / 実施ID / 期 | 成績のブックの課題管理の A・C・D・I・J・K 列だけを `IMPORTRANGE` で引く（フォームや採点シートの URL は引かない）。実施ID が空の行は引かない |
| 進み具合（見る用） | 単元 / クラスごとの列 | 縦に単元、横にクラス。マスは「済み/予定の回数」。色は、途中が薄い緑・予定どおり終わったら濃い緑・予定より多いとオレンジ。中身は式 |
| 予定表（見る用） | クラス / 授業のある日付 | 縦にクラス、横に授業のある日。マスはその日の単元（中止は「中止」、単元が空なら「・」）。単元ごとに色を塗る。単元を足したら、メニューの「進み具合・予定表の色を作り直す」 |

使い方:

1. 学校アカウントで空のスプレッドシートを作り、「拡張機能 → Apps Script」に `Plan.gs` を貼って保存する
2. `setup` を実行する（初回は権限の確認が出る）。スプレッドシートを開き直すと、メニューに「授業計画」が出る
3. 設定のシートに期間・時間割の切り替え・成績のブックの URL を書き、メニューの「課題の引き込みを作り直す」。課題のシートの A2 で「アクセスを許可」を押す
4. 時間割と日のシートを書き、メニューの「授業の行を足す」。もう一度押しても、ある行は触らずに足りない行だけ足す（時間割の切り替えや日を後から足したとき、もう作ってある行は消さないので、手で消す）
5. 祝日は Google カレンダーの「日本の祝日」から読む。学校アカウントでそのカレンダーを登録していないと読めず、祝日にも行ができる

## GAS を公開する

1. Apps Script で `Code.gs` の中身に置き換えて保存する
2. `testRun` を実行して、ログに「注意」が出ないことを見る
3. 「デプロイ → 新しいデプロイ」。種類は「ウェブアプリ」、実行するユーザーは「自分」、アクセスできるユーザーは「全員」
4. 出てきた URL（`…/exec` で終わる）を、表示ページの「設定」に入れる。合言葉も入れる

コードを直したら、「デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン」で上げる。こうすると URL は変わらない。
合言葉が漏れたら `makeToken` をもう一度実行する（古い合言葉は効かなくなる。各機械の設定も入れ直す）。

## 手元で見る

```
python -m http.server 8790 --bind 127.0.0.1
```

（Mac では `python3`。Windows と Mac で確かめた）

`http://localhost:8790/?sample` を開く。

ブラウザに貯めた分は、今週より 4 週前より古い週のものを、読み込むたびに消す。
